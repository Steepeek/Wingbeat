# Звук сигнала

Положите сюда файл `.wav`, `.mp3` или `.ogg` — метр возьмёт первый по
алфавиту как сигнал по умолчанию. Свой файл можно указать в настройках,
вкладка «Сигналы».

Сами звуки в репозиторий не кладутся: у стоковых файлов бывает лицензия,
не допускающая распространение. Если собираете сборку для раздачи —
проверьте лицензию своего файла.
